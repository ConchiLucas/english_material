# Agent 生成结果分页展示设计

## 目标

为已经完成的故事 Agent 批次提供独立、直观的最终结果浏览页面。用户从顶部“英语素材项目”入口展开“Agent 生成结果”，按页连续阅读多个最终故事，而不进入运行审计界面逐个选择批次。

第一版只展示故事 Agent 的最终故事，不展示图片结果、Agent 中间输入输出、评分、Token、质量轮次或其他执行细节。

## 导航

- 顶部新增“英语素材项目”可展开入口。
- 点击入口打开下拉菜单；再次点击、点击外部或选择菜单项后关闭。
- 第一版下拉菜单只有“Agent 生成结果”。
- 配置管理、去重单词表、Agent 工作台和图片工作台保持当前一级位置与行为。
- 选择“Agent 生成结果”后进入独立结果页，并在导航中明确显示当前选中状态。
- 键盘用户可聚焦入口，以 Enter 或 Space 展开，以 Escape 关闭，并可通过方向键选择子菜单。
- 窄屏沿用同一信息层级，以可访问的弹出菜单展示子项，不增加常驻第二行导航。

## 页面布局

页面采用“顶部下拉 + 阅读档案”方向，视觉延续现有深色工作台，但将装饰控制在最低限度，让最终故事成为视觉主体。

页头包含：

- 英文辅助标识 `ENGLISH MATERIAL / RESULTS`。
- 主标题“Agent 生成结果”。
- 当前结果总数。
- 每页数量选择：10、20、100，默认 10。

页头下方是单列结果列表。每条结果使用一个占满内容区域宽度的块，块高度由正文自然撑开，不使用固定高度、内部正文滚动或折叠预览。

每个结果块分为上下两层：

1. 标题层固定一行，超出可用宽度时显示省略号；右侧保留“复制全文”操作。
2. 内容层展示完整最终故事，保留 Scene 标题与自然段换行，不解释 Markdown，不把 Markdown 标记渲染为格式化内容。

标题格式固定为：

`首个 Scene 标题 · 年级 · N 个单词 · MM/DD HH:mm`

示例：

`The Wrong Recipe · 三年级上册 · 20 个单词 · 08/16 08:08`

如果首行不符合合法的 `Scene N: Plain English Title` 格式，标题使用“未命名故事”；正文仍原样展示。年级为空时显示“不限制”。标题中不显示批次 UUID。

## 分页行为

- 服务端按创建时间倒序分页，最新结果优先。
- 默认每页 10 条；用户可切换为 20 或 100 条。
- 切换每页数量时回到第 1 页。
- 切换页码或每页数量成功后，页面滚动到结果区顶部。
- 翻页请求期间保留当前内容，防止长故事列表闪空。
- 如果数据变化导致当前页超出总页数，自动请求最后一个有效页；没有结果时保持第 1 页。
- 不把页码和每页数量持久化到服务端。第一版可仅保留在当前页面状态，不要求刷新后恢复。

## 后端接口

新增专用接口：

`GET /api/story-runs/results?page=1&pageSize=10`

约束：

- `page` 从 1 开始，必须为正整数。
- `pageSize` 只允许 10、20、100；缺省为 10。
- 数据库查询只选择 `COMPLETED` 且 `finalStory` 非空白的批次。
- 排序固定为 `createdAt DESC, id DESC`，保证相同时间戳下分页稳定。
- 分页、状态和非空条件均下推数据库，禁止先全量读取后在内存分页。
- 不加载 Agent 步骤表，避免 N+1 和无关长文本。
- 最终故事继续遵守现有故事快照长度边界。

响应使用明确的分页 DTO：

```json
{
  "items": [
    {
      "runId": "批次 ID",
      "title": "The Wrong Recipe",
      "targetGrade": "三年级上册",
      "wordCount": 20,
      "finalStory": "完整最终故事",
      "createdAt": "2026-08-16T08:08:00+08:00"
    }
  ],
  "page": 1,
  "pageSize": 10,
  "totalItems": 126,
  "totalPages": 13
}
```

`runId` 用于 React 列表稳定 key 和后续扩展，不在第一版界面标题中展示。`title` 由后端从经过验证的最终故事首个 Scene 标题提取，前端不维护第二套解析规则。

## 前端组件边界

- `App` 负责“英语素材项目”展开状态、当前一级页面和未保存工作台的离开保护。
- 新建结果页组件，负责分页状态、请求竞态隔离、加载/空/错误状态、复制和滚动定位。
- `api.ts` 只负责序列化合法分页参数并返回逐字段类型的分页响应。
- 页面组件不复用全屏 `StoryRunHistory`；两者目标不同：运行记录用于批次审计，本页面用于跨批次连续阅读。
- 离开 Agent 工作台或图片工作台进入结果页时，继续复用现有未保存草稿确认逻辑。

## 加载、空状态与错误

- 首次加载展示与结果块等宽的骨架屏。
- 无数据时显示“还没有可展示的 Agent 生成结果”，不展示空分页器。
- 首次请求失败时保留页头，显示有界错误说明和“重新加载”。
- 翻页失败时保留现有结果与当前页，显示非阻塞错误提示；用户可再次点击目标页重试。
- 快速切页时使用请求序号或取消信号丢弃旧响应，防止迟到结果覆盖当前页。
- 复制成功使用与现有界面一致的轻量提示；浏览器拒绝剪贴板权限时给出明确失败提示。
- 最终故事只通过 React 文本节点渲染，不使用 `dangerouslySetInnerHTML`。

## 可访问性与响应式

- 项目入口与子菜单使用 Ant Design Menu 的可访问菜单语义，不自制不可聚焦下拉层。
- 结果集合使用语义化列表；每个结果块使用具名 `article`。
- 标题保留完整 accessible name，即使视觉上省略。
- 复制按钮具有包含故事标题的 accessible name。
- 页码和每页数量控件具备明确标签，键盘可完整操作。
- 宽屏保持单列全宽；窄屏标题元数据允许视觉压缩，但正文不产生横向滚动。
- Scene 标题和正文采用适合长篇英文阅读的行宽、行高和段间距；不引入额外动画。

## 测试

后端测试覆盖：

- 只返回 `COMPLETED` 且最终故事非空的批次。
- 10、20、100 三种页大小及非法参数拒绝。
- 数据库分页、稳定倒序、总条数和总页数。
- 首个 Scene 标题提取、缺失标题回退、空年级回退。
- 不查询步骤仓库。

前端测试覆盖：

- “英语素材项目”展开、关闭、键盘操作和唯一子菜单。
- 进入结果页时复用 Agent/图片工作台未保存保护。
- 默认请求第 1 页 10 条。
- 切换 20/100 条回到第 1 页。
- 翻页、请求旧响应隔离和成功后滚动到顶部。
- 标题单行内容、完整故事正文、复制全文。
- 首次加载、空数据、首次错误重试和翻页错误保留旧内容。
- 响应式布局不产生横向裁切。

## 明确不做

第一版不包含：

- 图片生成结果。
- Agent 中间输入或输出。
- 关键词、年级、日期筛选和全文搜索。
- 删除、编辑、重新运行、导出或批量操作。
- 评分、Token、通过状态和质量预算。
- 卡片折叠、摘要预览、虚拟滚动或无限滚动。
